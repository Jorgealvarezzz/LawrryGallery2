# LAWRY Gallery
Tienda de Sneakers & Streetwear - Proyecto Segundo Parcial

## Descripcion
Aplicacion web de comercio electronico para sneakers de lujo. Permite visualizar el catalogo, filtrar por categoria, buscar productos y gestionar el inventario con operaciones CRUD.

## Tecnologias
- Back-end: Python 3 + Flask
- Base de datos: SQLite
- Templates: Jinja2
- Front-end: HTML5 semantico + CSS3 + JavaScript vanilla

## Como ejecutar
pip install -r requirements.txt
python app.py

Tienda: http://127.0.0.1:5000
Admin: http://127.0.0.1:5000/admin
